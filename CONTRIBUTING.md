# Contributing

This repository is **public to read, but closed to changes**.

- Only the owner (@MrChartist) can change the `main` branch. Pull requests are not
  accepted unless the owner has invited you to submit one.
- Forks are allowed for **personal, non-commercial use only** (see [LICENSE](LICENSE)).
  Forks may not be published, re-hosted or used commercially.
- Found a bug or a security issue? Open an issue with details, or see [SECURITY.md](SECURITY.md).
  Do not include secrets, keys or private data in issues.
- Anything you submit may be used by the owner without obligation to you.
- Commercial use of any kind needs a written licence: see [COMMERCIAL-LICENSE.md](COMMERCIAL-LICENSE.md).
